# 网站验收清单

本地内容验收、代码验收与最终远程网站验收分别记录。不能把一次构建、一个 Library 压缩包或本地地址当成全量网站完成。

## 阅读与溯源

- 页首仅保留一句简短编译说明。详细稿件编号、字幕条数、时间范围、索引日期及编辑范围收在文末默认折叠的“编辑与来源说明”。
- 章节正文不重复显示独立成段的整行 VTT/本地时间轴说明；原有定位行逐章保留于文末展开区，章节标题旁只显示一个小号时间标记。定位若与科学正文同段，整段保留在阅读区。
- 原稿的疑误、研究条件与不确定性说明继续保留在相关正文处，不作为制作说明删去。
- 原节目来源和章节链接只来自已核实身份。第一期视频 ID `H-XfCl-HpRM` 由父任务提供此前核实结果；15 个章节起点已与实际本地 VTT cue 及对应内容核对。原音是否与字幕逐秒对齐仍未独立确认。
- 其余节目按原标题核对官方完整期页面、官方实际视频链接及封面，保存证据、身份与日期；未验证时保持空值，不按标题推算或补造 ID。完整期与 Essentials 日期和视频必须分别核对。
- 无核实视频链接的时间标记显示为本地定位，不能生成虚构回听 URL。不得将目录索引日期当作首发日期。

## 人物与素材

- 目录使用主持人单人照片时，图片 alt 只写照片中的 Andrew Huberman；双方姓名仍保留于卡片正文。来宾节目卡片应有清楚的“主持人”照片说明。
- 来宾文章页没有核实照片时使用明确头像占位，不把主持人照片说成来宾照片。
- 最终可补核实的来宾素材，或继续清楚标识主持人与来宾占位；人物身份和素材分发范围均需可追溯。

## 版式与交互

- 首页为大报头、报头下单行口号、紧凑搜索/范围/类别控件、左 16:9 真封面右编辑标题、三栏图文目录；手机为同一页面自然堆叠。
- 封面必须逐期匹配、解码尺寸并看实际画面；不拿人物头像代替节目封面。未核实项保持文字待核实。精选只选独立审核通过且有已核封面的文章。
- 搜索、类别与阅读范围按 AND 组合；按钮选中状态、空结果和清空恢复正确，移动端控件不溢出。
- 沿用已认可的白底、宋体正文、细线和桌面右侧目录；手机为同一页面、可折叠目录，无横向溢出。
- 原生来源折叠区可键盘展开与收起，来源细节不依赖额外脚本；新增组件使用当前站点的字号、间距和颜色。
- 检查字号、浅/深阅读底色、目录跳转、目录点击后收起、回到页首和本地资源。
- 回归检查覆盖单人照片 alt 与多参与者文字的区分、来源证据保留、重复定位行移出正文，以及不确定性编辑注仍在正文。

## 最终交付门槛

- 每篇正文与独立全文审核记录的最终哈希一致；修改已审文章时保留旧快照与限定差异审核，不无依据沿用旧哈希。
- 源 TXT/VTT 保持不变；目录类别、节选状态与完成状态准确。
- Library 预览更新同一身份，成功后保存返回版本；压缩包不含原始英文字幕、凭据或隐藏部署配置。
- 全量生产仍按实际逐篇进度记录；最终远程私有 Sites 的接入和可访问验证由父任务协调。未完成项不得标成最终通过。
