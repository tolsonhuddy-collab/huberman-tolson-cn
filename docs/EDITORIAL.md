# 长文编辑规范

## 稿件目标

读者只会中文。文章应让读者不依赖英文、在中文中读懂本期前段、中段、后段的主要论证和解释。目标形式为科普杂志长文，通常万字左右，长度由原稿信息量决定。不能为了字数填充，也不能因达到长度门槛就声称完整。

以节目实际展开顺序为基础，把相邻论证组织成自然标题与段落。保留有解释作用的例子、因果链、研究条件、适用范围与反例。删广告、片头预告的重复、订阅口播、寒暄与无意义重复；删除区间在作者覆盖表中记账。

## 行文

段落之间靠内容衔接，用原稿已有的实验与例子展开。避免“下面我们来”“值得注意的是”“不仅……更是……”等套语，避免每节结尾强行总结、机械三点罗列、夸大意义和励志金句。不新增故事、人物对白、编辑亲历或原稿没有的科学结论。

去除文风中的多余限定语时，不得删除科学意义上的“可能”“似乎”“动物实验”“目前不知道”。个人经历、研究结果、解释性类比和来宾观点分清归属。不要把旧节目转述当成最新医疗指南。

## 访谈与专名

主持与来宾首次出现给出中文名和英文名；问答、立场、例子和经验应清楚归属。可改写为连贯叙述，但不把意译加引号冒充逐字原话。术语另存逐篇词表，保留英文检索形式；未确定的译名或识别词标为待核。

## 疑误与来源

识别错误和前后矛盾须留下可定位的编辑注，不静默修成未经证据支持的结论。数字、单位、剂量、药物及内分泌术语重点复核。只保留真实可追溯的来源与时间戳；没有视频ID就不生成回听链接。索引日期及 VTT 时间轴明确注明未独立核实。

## 逐篇文件

`private/articles/{id}.md` 为正文；同目录 `{id}.glossary.json` 为术语表。`private/reviews/{id}.author-review.json` 为作者全文覆盖自查，包括逐段源时间范围到成稿小节的映射、广告和无效内容的删除、疑点及检查结果。

独立审核存 `private/reviews/{id}.independent-review.json`，至少包含 `review_kind: independent_editorial_review`、`verdict: pass|needs_revision`、`article_sha256`、审稿者、覆盖范围、发现的问题及修复。审核针对确切稿件哈希；改稿后重新验收。

## 验收口径

先检查原稿前中后是否全部读过，再逐段对照主题、解释和重要例子有无遗漏。重读不确定性和疑误注，检查采访发言人，检查文章能否自然连读。独立编辑可判定稿件达成本次精读标准，不等于核实每个科学断言或原视频完整。

状态顺序为 `pending → drafting → draft_complete → reviewed`。需要修订时使用 `needs_revision`；不能跳过实稿和审核。读者验收、来源视频身份核验和医学事实更新是另外的核对，不因 `reviewed` 自动通过。
